# Vendor Terms Summary (internal)

## Aeron (footwear)
- Lead time: 21 days. MOQ 240 units/style. Payment: net 45.
- Markdown support: 40% of markdown dollars reimbursed if claimed within 60 days
  of the markdown taking effect. Unclaimed support is pure self-inflicted margin loss.
- Returns: no vendor returns. Overbuys are ours forever.

## Northwall (outerwear, cold-weather footwear)
- Lead time: 45–52 days. MOQ 500 units/style. Payment: net 30.
- Markdown support: none. Seasonal cancellation window closes 90 days pre-season.
- Cancellation after the window incurs 22% of order value.

## Basics Co (apparel)
- Lead time: 14–18 days, domestic. MOQ 1,000 units. Payment: net 60.
- Markdown support: 25%, claimable quarterly.
- Replenishable weekly; there is no excuse for a Basics Co stockout.

## Kitchenly (small appliance)
- Lead time: 34–40 days. MOQ 300 units. Payment: net 45.
- Markdown support: 30% but ONLY on units bought in the same season as the markdown.
  Aged units get zero support. This is where escalating markdowns quietly become
  100% ours.
- Price protection: 1 rolling quarter on cost decreases if claimed.

## Soniq (electronics)
- Lead time: 19–26 days. MOQ 400 units. Payment: net 30.
- MAP (minimum advertised price) enforced: advertising below MAP forfeits co-op funds.
- Co-op advertising: up to 4% of purchase value, claimable semi-annually.

## Claims discipline
Every markdown recommendation on a vendor with markdown support MUST state
whether support is claimable and by when. An unclaimed rebate is a margin leak
owned by Buying.
